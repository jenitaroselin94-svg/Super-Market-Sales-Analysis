# Supermarket Sales Analysis Project
# Overview :

This project analyzes supermarket sales data to identify product performance, sales trends, and monthly revenue patterns. The goal is to understand customer purchasing behavior and improve business decision-making.

# Objectives :

Analyze supermarket sales data.
Identify top-selling product lines.
Analyze monthly revenue trends.
Visualize sales performance using charts.
Understand sales patterns and business growth.


# Technologies Used :
Python
Pandas
Matplotlib
Jupyter Notebook


# Dataset Features :
Invoice ID
Branch
City
Customer Type
Gender
Product Line
Unit Price
Quantity
Date
Payment
Sales


# Project Workflow :
Data Collection
Data Loading
Data Cleaning
Missing Value Checking
Date Conversion
Product Line Sales Analysis
Monthly Revenue Analysis
Data Visualization
Sales Trend Identification
Business Insights Generation


# Analysis Performed :

# Product Line Sales Analysis

Grouped sales by Product Line.
Identified highest-selling product categories.
Visualized results using a horizontal bar chart.


# Monthly Revenue Analysis
Extracted month from the Date column.
Calculated total monthly revenue.
Visualized revenue trends using a line chart.


# Results:

Identified the highest-performing product lines.
Analyzed monthly revenue growth patterns.
Generated visual insights for business decision-making.


## 📊 Results and Analysis:

# 1. Highest sales by product line :

- Product line sales analysis shows different categories have different revenue levels.
- Some product lines are highest performing, others are lower.
- Monthly revenue analysis shows sales variation across months.
- Highest revenue months indicate peak sales periods.
- These insights help in better stock planning and business decisions.
